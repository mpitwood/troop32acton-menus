# Menu Index — Backpacking

Same a la carte browsing as the front-country index — pick one main per
meal slot, add snacks, check the Diet/Allergen columns before picking.
This folder is sized for **3-night trips carried fully from the
trailhead, no resupply**. See [README.md](README.md) for weight/calorie/
protein targets, fuel-cost cook method tags, and trash/bulk guidance
specific to backpacking.

Most dinners (and one breakfast) use **vegetarian base + meat boost** —
weight for the boost is per meat-eating scout, not the whole patrol; see
each page's Scaling Notes. Breakfast and lunch pages that aren't
one-pot dishes use a parallel **protein side** swap instead of a boost.

## Sample day's menu (per person, 3-night trip, no resupply)

Core meals alone land close to the ~2,500 kcal / ~90-95g protein
Philmont derives from its own breakfast + lunch + dinner — snacks are
what push a harder day up toward the 2,600-2,900 kcal target range in
[README.md](README.md).

| Meal | Pick | Weight/Calories (meat-eater) | Protein (meat-eater) | Weight/Calories (vegetarian) | Protein (vegetarian) |
|---|---|---|---|---|---|
| Breakfast | Hot Oatmeal Bar + protein side | 5.3 oz / ~683 kcal | ~27g | 5.3 oz / ~613 kcal | ~24g |
| Lunch | Trail Tortilla Wrap Bar | 8.5 oz / ~950 kcal | ~38g | 7.75 oz / ~840 kcal | ~32g |
| Dinner | Backcountry Mac and Cheese | 6.75 oz / ~828 kcal | ~38.5g | Lentil Couscous Curry, 6 oz / ~650 kcal | ~34g |
| **Core total** | | **~20.55 oz / ~2,461 kcal** | **~103.5g** | **~19.05 oz / ~2,103 kcal** | **~90g** |
| + optional snack | Trail mix | +3.5 oz / +440 kcal | — | +3.5 oz / +440 kcal | — |
| **Day total with snack** | | **~24.05 oz / ~2,901 kcal** | **~103.5g** | **~22.55 oz / ~2,543 kcal** | **~90g** |

Both paths land well under the 2 lb (32 oz)/person/day weight target,
and the core-meals-only total already sits close to Philmont's own
~2,500 kcal / ~90-95g protein baseline — add a snack on harder days to
push toward the upper end of the range, skip it on easier ones. This
combination is illustrative; swapping any main for another on the same
course keeps totals in a similar band since all pages in a course were
recalibrated to the same target.

Longer treks with a resupply option (5+ nights) would need different
portioning per leg — not covered by this folder yet.
