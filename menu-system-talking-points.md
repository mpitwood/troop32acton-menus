# Menu Book — Troop Intro (2-3 min)

Give this same short rundown twice: once to patrol leaders, once to the
troop at large. Bullet fragments only — these are speaking notes, not a
script. Glance and talk, don't read it aloud.

## Why we're doing this

- Menu planning used to be scrambled together the week before, eating up
  a whole troop meeting — pre-planning aims to cut that down a lot.
- Choose from the provided recipes — shopping lists, allergy tags, and
  cost estimates already included.
- For now: Front-Country (car camping). Backpacking (trail) will
  follow.
- For now: printed recipes. Putting them on a website is an option
  later.

## How to use it

- One Main per meal slot, plus a Side or Dessert where the meal calls
  for one.
- Check the tag bar first — diet (nut-free, egg-free) and cooking
  method (Dutch oven, etc.) — before picking a recipe, not after.
- Advance Prep (at home) vs. Onsite (at camp) — recipes split it out,
  but the patrol still needs to plan *who's* doing which part.
- Any deviation from the menus needs advance approval from a scoutmaster
  or committee member.
- Only one Dutch oven recipe per meal — no time to cook a main, let it
  cool, clean the oven, and cook a dessert too.

## Vegetarian & allergy policy

- Vegetarian base + meat boost, cooked separately, added at serving —
  not two separate meals.
- Nut-free / egg-free tagged on every recipe — always double-check
  actual labels at the store, brands change.

## Nutrition

- "Real Food Check" instead of calorie counting — protein, vegetables,
  real food vs. processed shortcuts.
- Once Backpacking recipes are available: they'll also track food/fuel
  weight and calories/protein per serving.

## Pricing

- Weekend budget target: roughly $25/scout — that's a full weekend
  (Friday dinner through Sunday breakfast, plus snacks/dessert), not
  just one day's three meals.
- Every recipe has a cost estimate built in, but it'll take a few real
  trips before we know how realistic these are — flag it to the
  scoutmasters if a weekend's running over.
- Some ingredients (spices, oil) are flagged "take from home if
  available" — no need to buy a whole bottle for a teaspoon.

## Advancement — in priority order

Order below is for a short (2-meal) campout. On a longer campout with
more meal slots, move First Class candidates (#3) up — they need
multiple meals to satisfy req 2a, so give them the room when it's there.

1. **Tenderfoot → Second Class:** req 2e, cook a hot breakfast or lunch.
2. **Scout → Second Class:** pair with a Tenderfoot scout cooking for
   #1 — earns the Scout their own Tenderfoot requirement; if they've
   already got Tenderfoot, the same pairing counts toward their Second
   Class req 2e instead.
3. **Second Class → First Class:** req 2a, plan *and* cook all three
   meals, explain the nutrition using the Real Food Check.
4. **Cooking and Camping merit badges:** priority to oldest/highest-rank
   scouts.

## Close with

- Everything will be in the book and, later, on the website.
- Senior scouts should use their experience to help newer ones through
  it, campout by campout.
