Menu Index — Front-Country (Car Camping)

Browse a la carte: pick one Main per meal, add a Side/Appetizer if you want one, and a Dessert for Saturday dinner. Filter by the Diet/Allergen columns before you pick, not after. Every course below now has 6 options. See README.md for the full system and TEMPLATE.md to add new pages.

Most dinner and breakfast mains are vegetarian base + meat boost: one shared vegetarian-hearty pot/packet/dish, with meat browned separately and added to individual servings by scouts who want it — see the "Vegetarian policy" section of the README for why. Cost is shown as base cost per scout + meat boost per meat-eating scout — both figures are already per-person; a meat-eating scout's actual cost is base + boost, a vegetarian scout's is base only.

All prices are Boston-area estimates — see README.md#pricing-basis for what's directly sourced vs. scaled, and don't treat these as receipts.

At Boston pricing, the meat-eating scout's total still fits under $25/scout, but with much less slack than it would at national pricing — there's roughly $3.50 left for a Friday dinner, and any grocery run that runs over pushes past budget. See README.md#pricing-basis for where these numbers come from and why this is a real conversation to have with the committee about the $25 figure.
