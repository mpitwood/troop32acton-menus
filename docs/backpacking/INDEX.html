Menu Index — Backpacking

Same a la carte browsing as the front-country index — pick one main per meal slot, add snacks, check the Diet/Allergen columns before picking. This folder is sized for 3-night trips carried fully from the trailhead, no resupply. See README.md for weight/calorie/ protein targets, fuel-cost cook method tags, and trash/bulk guidance specific to backpacking.

Most dinners (and one breakfast) use vegetarian base + meat boost — weight for the boost is per meat-eating scout, not the whole patrol; see each page's Scaling Notes. Breakfast and lunch pages that aren't one-pot dishes use a parallel protein side swap instead of a boost.

Sample day's menu (per person, 3-night trip, no resupply)

Core meals alone land close to the ~2,500 kcal / ~90-95g protein Philmont derives from its own breakfast + lunch + dinner — snacks are what push a harder day up toward the 2,600-2,900 kcal target range in README.md.

Both paths land well under the 2 lb (32 oz)/person/day weight target, and the core-meals-only total already sits close to Philmont's own ~2,500 kcal / ~90-95g protein baseline — add a snack on harder days to push toward the upper end of the range, skip it on easier ones. This combination is illustrative; swapping any main for another on the same course keeps totals in a similar band since all pages in a course were recalibrated to the same target.

Longer treks with a resupply option (5+ nights) would need different portioning per leg — not covered by this folder yet.
