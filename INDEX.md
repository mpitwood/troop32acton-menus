# Menu Index — Front-Country (Car Camping)

Browse a la carte: pick one Main per meal, add a Side/Appetizer if you want
one, and a Dessert for Saturday dinner. Filter by the Diet/Allergen columns
before you pick, not after. Every course below now has 6 options. See
[README.md](README.md) for the full system and [TEMPLATE.md](TEMPLATE.md)
to add new pages.

Most dinner and breakfast mains are **vegetarian base + meat boost**: one
shared vegetarian-hearty pot/packet/dish, with meat browned separately and
added to individual servings by scouts who want it — see the "Vegetarian
policy" section of the README for why. Cost is shown as **base cost per
scout + meat boost per meat-eating scout** — both figures are already
per-person; a meat-eating scout's actual cost is base + boost, a
vegetarian scout's is base only.

All prices are **Boston-area estimates** — see
[README.md#pricing-basis](README.md#pricing-basis) for what's directly
sourced vs. scaled, and don't treat these as receipts.

## Sample weekend menu (patrol of 6, 5 meat-eaters + 1 vegetarian)

Base cost is per scout; boost cost is per meat-eating scout — a
meat-eating scout's total for a meal is **base + boost**, a vegetarian
scout's is **base only**.

| Meal | Pick | Base | Boost (per meat-eater) |
|---|---|---|---|
| Sat breakfast | Breakfast Burrito Bar | $2.95 | $0.85 |
| Sat lunch | Campfire Quesadillas (assemble-your-own, same for everyone) | $4.20 | — |
| Sat dinner | Dutch Oven Chili + Garlic Biscuits + Peach Cobbler | $3.15 + $1.60 + $2.05 = $6.80 | $1.65 |
| Sun breakfast | Oatmeal Toppings Bar | $2.20 | — |
| Snacks | Campfire Kettle Popcorn + Ants on a Log | $0.80 + $2.10 = $2.90 | — |
| **Total, meat-eating scout** | | | **~$21.55** |
| **Total, vegetarian scout** | | | **~$19.05** |

At Boston pricing, the meat-eating scout's total still fits under
$25/scout, but with much less slack than it would at national pricing —
there's roughly $3.50 left for a Friday dinner, and any grocery run that
runs over pushes past budget. See
[README.md#pricing-basis](README.md#pricing-basis) for where these numbers
come from and why this is a real conversation to have with the committee
about the $25 figure.
